# 衡策 Escape V3：NO-GO

本次完成工程修復、來源核對、歷史重算及預警比較。**V3 狀態機可以解除高風險鎖定；沒有證據支持把它保留為已驗證的預測功能。正式交易權限 NONE，不上線。**

## 結論與比較

先凍結一套 V3 規則，再執行結果比較；未搜尋參數、未挑選表現最佳級別。原始風險仍直接使用凍結的 V1 detector 與不帶 prior_level 的 V2。持續狀態使用最近五筆連續有效觀測的最高原始風險；立即升級，舊證據到期後降級。缺值不當作復原，會清除降級確認窗，對外回傳 UNVERIFIED，內部保留舊狀態。

2025–2026 合併、時間隔離後，L2+ 警報的條件命中率如下。這是警報後達到跌幅目標的比例，不是獲利率或交易勝率。

| 未來期間／目標 | 有效日 | V3 | 原始風險 | 價格動能基準 | 市場廣度基準 |
|---|---:|---:|---:|---:|---:|
| 5 日 ≤ −3% | 417 | 15.46% | 19.58% | 17.73% | 14.12% |
| 10 日 ≤ −5% | 407 | 4.46% | 5.07% | 14.18% | 10.48% |
| 20 日 ≤ −5% | 387 | 9.18% | 10.29% | 16.06% | 13.45% |

價格基準為截至當日 E 族群等權連鎖報酬的 20 日動能 < 0；市場基準為 U 族群收盤高於 MA20 的比例 < 50%。全程使用相同樣本。U/E 是現存歷史研究代理，並非已通過獨立 PIT 認證的官方電子類指數。

20 日 V3 共 196 個警報日，其中 18 日達目標。誤報占警報比例 **90.82%**；傳統假陽性率 **52.35%**；目標日召回率 **38.30%**。價格基準相應為 83.94%、33.82%、46.81%。兩種誤報率的分母不同，不能混稱。

V3 的年度表現不穩定：20 日命中率 2025 年 5.61%、2026 年 13.48%；價格基準分別 18.37%、10.26%。2026 年較好不能抵銷 2025 年失敗，也不能選擇性報告。六項配對區塊 bootstrap 比較均未取得多重比較修正後的正下界。7/30 個預先規定檢查成立，整體判定 NO-GO；此數字不是預測正確率。

## 狀態機結果

直接執行凍結原版程式，重現 V2 首次 L6 日期 2024-07-30，此後無法解除。2025–2026 全資料 438 日均 L6；排除 2026-10-08 起的資料後為 **427/427**，這才是舊報告 427 日的範圍。V3 在該兩年沒有 L6，會隨近期原始風險降回較低狀態。這是反事實歷史整合測試，不代表現行正式系統曾被鎖住。

V3 保留五日風險記憶的代價是延長警報、增加假陽性；修復永久鎖定並未改善預測價值。缺失資料連續存在時仍會保留內部舊值，但公開狀態為 UNVERIFIED，不宣稱風險消失。

## L1–L6 與事件級結果

20 日隔離樣本內，V3 **恰好** L1/L2/L3 的樣本數為 116/176/20，命中率為 12.07%/9.09%/10.00%。L4/L5/L6 均無樣本，判定資料不足，不可寫成零風險或高準確率。原始風險、V2、V3 的各級「恰好」與「至少」效果，5/10/20 日、各年度均完整保留於 comparison_metrics.csv。

固定交易日錨點每 h 日取一次，產生不重疊報酬區間（nonoverlap_calendar），不因警報調整抽樣。另以結果本身依序選出不重疊的 h 日下跌區間，用來衡量事件召回與提前量。20 日合併樣本只有 **5 個**此類區間：V3 捕捉 2/5、價格動能 4/5、市場廣度 5/5。命中事件的提前量中位數分別為 19.5、9、5 個交易日；只在命中事件中計算，V3 的較長提前量不能解讀成整體較佳。這些區間雖不重疊，仍可能屬於同一市場下跌過程，不宣稱統計獨立。

## 執行方式

Python 3.12、numpy 2.3.5、pandas 2.2.3；無網路需求。從 repository root 執行：

```bash
python3 research/escape_v3_20261104/run_all.py REPAIRED.zip PATCH.zip VALIDATION.zip ORIGINAL_MOTHER.csv ORIGINAL_MARGIN.csv
```

五個輸入分別為已核對的 repaired research、702055 patch、先前 NoGo validation 包，以及 TWSE_2023_2025_mother.csv、TWSE_2023_2025_margin.csv。run_all 先驗證封存 SHA，再重算、測試、評估，產物僅寫入獨立研究目錄。不要從主交易引擎匯入研究 wrapper；它為了執行原版邏輯而在內部隔離了反事實 gate 假設，絕不表示 PIT 驗證通過。

來源索引、檔案 SHA-256、階段 commit 與交接狀態見 SOURCE_INDEX.json、FILE_SHA256_MANIFEST.json、HANDOFF.json。大型逐日表及完整比較表保存在交付 ZIP；GitHub 保存程式、規格、摘要、測試與雜湊。原始資料仍沿用既有已核對的封存檔，交付 ZIP 不重複打包數百 MB 來源。
