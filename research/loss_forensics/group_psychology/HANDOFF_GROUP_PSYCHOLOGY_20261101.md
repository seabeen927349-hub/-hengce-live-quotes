## Core research question

Can public market data identify states in which a large number of holders are likely to be pushed toward the same action at roughly the same time, and does that crowd state carry incremental out-of-sample information about subsequent price pressure?

Do not infer emotion directly. Test the observable chain:

`participation structure -> unrealized P/L pressure proxy -> trigger -> collective action -> price imbalance`

## First research cut

Start with the cleanest observable mechanism before attempting cost-basis reconstruction:

> When the number of small-position holders expands faster than the shares absorbed by those same TDCC buckets, does this participation diffusion contain incremental information about later price weakness after controlling for price run-up, turnover, volatility, margin, TotalHolders, Big400 and Big1000?

Use native TDCC buckets first. Do not invent a single “retail” threshold before the capability audit.

1. Bootstrap latest branch authority; preserve Stage H and Stage I.
2. Capability audit only — no new-family forward outcomes.
