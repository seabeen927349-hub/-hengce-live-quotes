# HENGCE 五日暴跌／抗跌差異研究 v0.1 (2026-11-05)

## 研究邊界

本研究只分析一個五個交易日的市場壓力事件，不是測底、選股、交易或預測模型。依 HENGCE 原血管與 EOD 收據：2026-11-05 `price/institutional/margin=PENDING`，所以正式五日研究使用 **2026-10-29、10-30、11-02、11-03、11-04**，比較起點為 **2026-10-28 收盤**。11/05 大盤收盤 41,574.72 屬經公開市場資訊核實的背景資訊，不得混入 HENGCE 正式母體五日個股研究，亦不可將研究衍生檔提升為 Canonical。

觀察母體：上市股票，代碼 4 位且首碼不為 0、6 日均具有效收盤價，五日平均每日成交金額至少新台幣 2,000 萬元，每日不得低於 200 萬元；**556 檔**。五天法人與融資餘額、起始融資餘額完整：**543 檔**。加上 10/07 前期收盤價與全部模型特徵：**542 檔**。僅限 TWSE、不含 TPEx。篩選規則是研究約定，不代表此篩選已獲最佳化。

## 資料與計算

資料來源：倉庫既有 `eod/YYYYMMDD/price_*.csv`、`institutional_*.csv`、`margin_*.csv`、`status.json`；股票名稱和原始資訊直接來自 TWSE 正式 EOD 分腿。嚴禁資料來源未完整時以其他供應商填空。

- 五日未還原價格報酬 = `100 * (Close_20261104 / Close_20261028 - 1)`。TAIEX 同期：47,035.58 → 42,948.91，即 **−8.69%**。
- 相對大盤 = 股票五日報酬 − TAIEX 五日報酬，單位百分點；不是風險調整 alpha。
- 期前走勢 = `100 * (Close_20261028 / Close_20261007 - 1)`，為事前可觀察變數。
- 融資變化百分比 = `100 * sum(MarginBalance - MarginPreviousBalance) / (first_day_MarginBalance - first_day_margin_delta)`；起始融資為零或無資料時設為缺失，不把 0 值視為下降。
- 法人淨流量佔成交金額的近似比例 = `100 * sum(法人淨買賣股數 * 當日收盤價) / sum(當日成交金額)`。僅為成交價近似，不等於實際成交資金明細。
- 需六個起迄日價量資料才能定義五日報酬；財報、產業分類、公司事件、除權息、實際流通股數不在本次完整驗證內，不能宣稱已排除這些混淆。

最弱的前 15 檔均見融資餘額減少，但法人合計買賣超不全是負值。反例：玉晶光跌 29.40%，五日法人合計淨買約 1,338 張；致茂跌 27.76% 但法人淨買約 254 張；台勝科跌 23.69% 但法人淨買約 4,119 張，且融資餘額下降約 31.45%。這表示法人資料不足以直接解釋每檔股價重挫的最終原因。

反向反例：麗臺漲 21.36%，法人合計淨賣約 522 張，融資增加 56 張；味全漲 11.54%，法人合計淨賣約 2,825 張，融資增加 1,250 張。

## 先前股價趨勢

10/07 到 10/28 事前走勢，與之後五日股票報酬的 Pearson 相關約 **+0.419**（553 檔），不支持「前期越漲，這次必然跌得越多」的通則。最弱組該前期走勢中位數約 **−9.31%**；最強組約 **+1.15%**。玉晶光為一個重要反例：前期約 +22.58%，隨後五日跌 29.40%。

## 對照的解釋性統計模型

對具備全部三項特徵的 542 檔，以五日報酬為被解釋變數、(1)期前價格走勢 (2)同期融資餘額變化百分比 (3)同期法人淨流量佔成交金額比 作解釋變數。OLS、截距、訓練折的 2%/98% 去極端值與 z-score，固定股票代碼雜湊五折 **同一事件橫斷面交叉驗證**：

| 模型 | CV R² | CV MAE（百分點） |
|---|---:|---:|
| 僅期前股價趨勢 | 0.1646 | 4.763 |
| 僅同期融資變化 | 0.1477 | 4.797 |
| 僅同期法人淨流量 | 0.0860 | 4.900 |
| 期前趨勢＋融資變化 | 0.2734 | 4.405 |
| 全三因子 | **0.3566** | **4.088** |

全三因子標準化係數（同期資料，非預測）：期前趨勢 **+2.22**、融資變化 **+2.45**、法人流量 **+1.96** 百分點（各自一個標準差，控制另兩因子）。模型仍有 **約 64% 的報酬變異未解釋**。

**關鍵治理：** CV 用的是同一場暴跌期間的不同股票，不是跨時段樣本外預測驗證；同期融資／法人是事件後才完成的資料，使用其解釋同一段價格構成明顯同時性問題（endogeneity）。**此模型不能事前操作、不能產生買賣訊號、不能宣稱獲利勝率或測底精度。** Q017 仍退役，研究分支不授予策略、交易、母體升格權限。
