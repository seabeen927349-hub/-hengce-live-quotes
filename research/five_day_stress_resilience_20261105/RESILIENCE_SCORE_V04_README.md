# 衡策 HENGCE｜抗跌分數 v0.4：數字化定義與單次事件測試

**狀態：研究探索、非交易模型。** 模型的輸入日期截止 2026-10-28；輸出是 0–100 **相對排名分數**，不是獲利機率或未來五天預測報酬。2026-11-05 的 HENGCE 價量、法人、融資母體仍 PENDING，不使用這一天做股票觀察值。

## 完整算法（固定且可重現）

研究母體：TWSE 股票代碼四碼、2026-10-07 有有效基準收盤、2026-10-14 至 10-28 的九個已存交易日日收盤均有效，且這九日的每日成交金額平均 ≥ 新台幣 2,000 萬元、**各日**不低於 200 萬元。股價只使用收盤價原值，未還原除權息。**全部 560 檔符合條件。**

令 `r_t=100×(C_t/C_(t−1)−1)`，其中前期的八筆日報酬依照 10/14、10/15、10/16、10/19、10/20、10/21、10/22、10/27、10/28 依序計算（10/14 是第一個收盤觀測日）。三項因子：
1. **波動 V**：上述八個 `r_t` 的母體標準差（百分點），數值越小越好。
2. **最慘一日 W**：上述八個 `r_t` 的最小值（百分點），數值越高越好。
3. **前期趨勢 M**：`100×(C_10/28/C_10/07 − 1)`，數值越高越好。

每項都在**事前合格的同一個股票母體**內換算 0～100 百分位（同值採平均名次）。`P_V` 是 V 由大到小的好壞名次；`P_W` 是 W 由小到大的百分位名次；`P_M` 是 M 由小到大的百分位名次。**總分 S = 0.50×P_V + 0.30×P_W + 0.20×P_M**。得分愈高表示這套規則下的相對抗跌特徵愈強。

分數分級：80–100／60–<80／40–<60／20–<40／0–<20。所有門檻與權重都是 **v0.4 暫定研究設定**，不是歷史獨立驗證後的最適參數。

## 驗證限制

- 本次權重是在看過該次暴跌現象後制定，因此即使全部輸入都截止於 10/28，**仍存在研究者事後選因子與調權重的選樣偏誤**，不是獨立的事前驗證。
- 只測一場市場大跌，沒有跨年份、跨市場狀態、跨期間樣本外測試。
- 非因果模型；沒有充分控制產業配置、原始波動 Beta、股利與除權息調整。
- 分數區間對應的 87.2%、15.5% 等只是**這一場事件的觀察頻率**，不可當未來機率。
- 「跑贏大盤」和「股票上漲」不同；80 分以上的股票在這次仍平均下跌 3.53%。
- 正式母體、交易、策略等權限維持不變，不建立第二母體或排程。
