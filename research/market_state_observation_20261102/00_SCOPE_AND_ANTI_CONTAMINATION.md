# HENGCE Market Environment Observation — Scope & Anti-Contamination Lock

Date: 2026-11-02 (Asia/Taipei)
Branch target: research/selection-challenge-20261102
Project path: research/market_state_observation_20261102

## Objective
Build a clean, literature-first research path for **contemporaneous Taiwan-equity market-environment observation**.

This project answers only:

> What market environment is observable **now**, using information that was genuinely available by that observation time?

It does **not** answer:

- what will rise next;
- which stock to buy;
- what future return follows a state;
- what threshold maximizes performance;
- what bull/bear label best explains the past.

## Anti-contamination rule
Any earlier HENGCE regime/state/model work that inspected target returns, tuned thresholds, optimized rankings, or otherwise preceded this literature gate is retained only as historical audit material and is treated as:

`PRE_LITERATURE_CONTAMINATED`

It may not be used as confirmatory evidence for this project.

This fresh path begins from the Taiwan-stock Master Corpus P1 closure authority dated 2026-11-02 and a topic-specific literature gate. No forward-return inspection has been used to define the observation architecture below.

## Clean-path sequencing
1. Master P1 literature foundation — completed at bounded `PROVISIONALLY_SATURATED` level.
2. Topic-specific Market State literature gate — required.
3. Preregistration of observation architecture — allowed only after topic gate PASS.
4. PIT/data-lineage capability audit.
5. Historical as-of reconstruction of environment observations only.
6. Only after a separate future gate may state classification or predictive testing be proposed.

## Hard prohibitions on this path
Until downstream governance explicitly changes:

- no forward-return discovery;
- no backtest of a new state hypothesis;
- no optimization of thresholds;
- no clustering selected because it improves returns;
- no label such as fear/FOMO/overconfidence unless directly identified;
- no "smart-money" identity assumption;
- no fixed upstream->downstream leader assumption;
- no universal high-volatility=risk-off rule;
- no rising-margin=crash rule;
- no composite market-state score invented from intuition.
