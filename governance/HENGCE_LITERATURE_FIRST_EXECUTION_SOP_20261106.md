# 衡策 HENGCE — 文獻優先研究執行規範（跨對話持續）
Version: 2026-11-06 / Status: MANDATORY / Scope: ALL HENGCE RESEARCH
Authority: additive implementation of governance/HENGCE_RESEARCH_LITERATURE_FIRST_CONSTITUTION_v1.md. This SOP strengthens, and never overrides, the original constitution, formal governance, mother, blood vessels, PIT, OOS, no-trade restrictions, and promotion gates.

## 永久指令：先找專業方法，學習後才設計／測試
使用者明確要求：「每次研究時，先找找別人的看法，再決定怎麼繼續。自己不懂就上網找答案，學習專業人士怎麼做，不要每次自己亂搞。」
This is a mandatory *research procedure*, not a claim that a published method necessarily produces alpha.

## 每次新研究／換對話的第一步
1. 從 GitHub 讀取本 SOP、上游文獻憲章、LITERATURE_GATE 合約及正式治理；接續先前輪次時，先讀前輪完整交接／凍結假設／失敗與淘汰紀錄，禁止憑對話印象重建。
2. 確認現有母體、資料血管、研究權限、原 MOM20 Top5 基準及 S5／Escape／RMS 不被擅改。不另建母體，不用外部資料繞過既有血管治理。
3. 為待解決的具體問題記錄：目前哪個地方不通、已知反證、可觀察的缺口與此輪只打算回答的問題。
4. 在任何新公式、特徵、門檻、買賣點、選股／開關或回測前，先通過原本的 literature-first gate。未通過：只能做文獻研讀、核對與非結果導向資料稽核。

## 專業資料搜尋與學習（必做）
1. 優先查找並閱讀**可核查的原始專業資料**：經同儕審查論文、學位論文、工作論文、學術/監管機構研究、可信量化研究的完整方法與證據；台股主張優先找台灣市場實證，也參考國際基準。
2. 廣泛查找並存檔支持、反對、無效、樣本外失敗、不同時期失效的證據；不能只找對自己想法有利的論文，不能以摘要或搜尋片段冒充全文閱讀。
3. 每項重要文獻至少記錄：作者、年份、題名、永久連結/DOI、取得日期、閱讀狀態（FULL_READ/PARTIAL/FOUND_ONLY）、研究問題、股票池與期間、訊號是否事前可得、方法、交易成本、主要表格、穩健性、反證、限制及**與衡策不相符的條件**。
4. 不懂統計／微結構／市場制度／方法時，先查原作者、方法專著或其他獨立專業解釋；仍無把握就列為 OPEN QUESTION，不用猜測補洞。公開資料學習 ≠ 直接向真人請教，未聯絡不得聲稱「已請教專家」。
5. 必須核對量化規則適用範圍：台灣市場交易制度、股票池/產業、上市存續偏差、價格限制、流動性、成交可行性、企業行動、可觀測時間點、風險/因子曝險、成本及換手率。
6. 依憲章，維護台股 Master Corpus 與 topic ledger；可取得全文卻未閱讀，不能假冒 PASS；主要相反證據未研究亦不可 PASS。

## 文獻之後才有研究決策
1. 用 Evidence Map 逐項對照：專家怎麼做、有效的市場與時段、反例、可否由衡策現有母體合法重現、解決衡策哪個具體缺口。
2. 寫下 Go / No-Go 判斷與原因。如果沒有可信機制、可觀察資料、反證評估或獨立樣本，停止**此提案**的回測；先學習，不等於放棄衡策整體目標。
3. Gate PASS 後，仍須先事前凍結假說、原版 Top5 基準、樣本切割、正確風險配對、現金期處理、成本/滑價、買入可行性、統計方法、多重試驗預算、成功/淘汰門檻，才允許依正式程序測試。
4. 禁止在已看過的2018–2025或2026績效上反覆調參製造勝利；歷史探索性結果不得聲稱乾淨樣本外。前瞻與真正未見資料須另立、不可偷看。
5. 結果失敗要報告並淘汰該假說，記錄反例；修復研究流程、資料品質或完成幾輪都**不是**已證明選股有超額報酬。不得為了湊下一輪而做無依據實驗。

## 每輪研究交付（換對話必讀）
每輪交接至少包含：
- 問題、文獻搜尋範圍、研究來源/DOI/連結、閱讀深度與確認日期；
- 正反/無效證據與方法適用性比較、仍不懂的地方；
- 憲章與主體/主題 literature gate 狀態；未 PASS 就清楚記 BLOCKED；
- 哪些決策來自專業文獻、哪些是假設、哪些是衡策已驗證事實；
- 預先凍結的研究設計或 No-Go 理由；
- 計算程式、輸入版本/雜湊、實驗結果與失敗清單；
- 白話結論、還沒解決的問題、下輪**先應閱讀的專業來源**；
- 明確標明是否有可重複、扣成本、樣本外超額報酬證據（若無，填 NO）。

## 無例外治理
- 既有文獻憲章及 literature_gate_check.py 是上游 gate；本 SOP 是人/研究流程補強，文檔寫入**不等於**已自動驗證閱讀真實性。
- 不得倒填文獻、假造已閱讀/已諮詢/已回測或資料已更新。外部資料必須遵守既有資料血管與來源權限。
- 本 SOP 不建立任何交易信號權、資金權、策略升級權；正式治理與風險控制保持原狀。
- 在新聊天中若無法取得 GitHub/前輪檔案，必須說明無法核實，不得憑空聲稱已讀；能取得時要先讀再繼續。
