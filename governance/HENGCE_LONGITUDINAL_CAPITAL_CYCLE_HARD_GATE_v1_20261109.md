# 衡策 HENGCE｜長期資金循環與播種／施肥／收割研究強制規則 V1.0

**狀態：正式研究治理約束／FAIL-CLOSED／不得以短期代理取代多年循環**  
**生效：2026-11-09（Asia/Taipei）**  
**適用：衡策所有研究、每日HBA偵查、Escape與市場環境解讀、單股／全股分析、跨股輪動研究、報告及後續聊天交接**  
**權限：研究方法與聲明門檻。沒有改動任何正式選股、倉位、下單、Escape或S5模型權限。**

## 1. 必須先研究「過去已做了什麼」，才能判斷「現在在哪個階段」

將外資、投信、自營商加總視為**同一個假想大型資金主體的研究代理**，連續追蹤全部可取得之多年原始買進、賣出、價格、成交量、融資、集保與跨股資料。這種加總只研究行為形態，**不代表三者必然共同控制、合謀、同一受益人或可直接推算已實現獲利**。

不能由當天／最後一週／五週／十二週的變化起頭就對既存資金階段下結論；不能因單日法人資料尚未發布就抹除已存在的歷史布局。研究單位是**從可核對歷史序列自然辨識的完整資金行為路徑**，不是事先切好的固定時間窗。

## 2. 必須連續檢查的資料（沿用既有血管，不重建）

1. **多年法人原始總量與分段路徑**：每股按可取得日期保留四支買進與賣出原始腿（外資、投信、自營商自行、避險），以及逐日 gross buy / gross sell、交易日、完整性、價格與成交量。單日與期間淨額只做輔助，不能代替交易總量或進出循環。跨年不中斷。
2. **價格／價值／成本代理**：同期價格路徑、成交量、推升成本與交易價差。全市場VWAP或收盤價不是法人實際成交價，估計成本與獲利必須標記代理限制。
3. **集保完整週序列**：使用全部當時已可取得、日期可核對的歷史週資料；400張以上、1000張以上、10張以下等級距要看持股股數、占比、持有人數、級距轉移及前後路徑。不同級距不是法人身分證明。週資料不得假造每日觀測或補零。
4. **資金動態**：探索累積、試探、推升、分批賣出、撤回、失敗、回補再試、局部換手、跨股輪動；多條路徑可重疊，不假設每次一定成功或一定有固定持有週期。
5. **反證及時間戳**：同期其他買盤、法人反向交易、價格不配合、來源不全、缺資料、重大事件、資料首次公開日期、是否有前視偏差，皆須採一致標準保留。不預先替機構找開脫，也不刻意忽略不利於假說的證據。

如研究某股的完整可用歷史長度不足，**必須明示涵蓋邊界與未能檢查部分**，可作為弱證據研究候選，不得偽稱已完成「2018–今全部軌跡」。

## 3. 強制禁止的捷徑（任一項都不能單獨作長期階段判定）

- 任意最後1週、5週、12週，或固定5日、10日、20／60／120日窗口的變化；
- 單日／一週／期間法人「淨買賣超」或期初期末持股比例；
- 僅以最近兩個集保週點位差，替代完整歷史級距軌跡；
- 只看今日漲跌／爆量／市場反彈，宣稱「正在播種」「資金回流完成」或「收割成功」；
- 以單一總買賣量累計摘要代替多年間的逐日進出及價格配對；
- 先替每檔股票貼上播種、收割等標籤，再為該標籤選擇有利時間窗和數據；
- 因缺乏共同控制人、法人真實成本或100%證明，就直接否定已觀測到的累計買賣與跨期活動；
- 把不同時間點才會公布的週資料或盤後資料，倒灌至過去盤中決策；
- 宣稱跨股輪動已被證明，卻沒有多檔間有共同時間基準、可重查的交易路徑；相似時序不代表同一資金流實際轉移。

**可保留短期雷達（HBA）的固定窗口作為人工偵查警示，但報告必須明確標為「SHORT_WINDOW_SURVEILLANCE_ONLY」，不得將警示名稱或候選排序升格成多年播種／收割結論。**

## 4. 自然邊界、完整循環與成功／失敗樣本

先從歷史逐日證據中的買賣強度、反轉、價格反應與週籌碼路徑識別**可能轉折事件**；再回看事件前後、跨年、跨個股的既有歷史。不得先指定每輪是5、20、60、120天。若以窗口只是為了快算／視覺化，須列為局部切片並保留完整版縱向稽核。

每個候選路徑都要同時記錄：累計買賣總量、淨額與反覆循環、價格與估計成本／價差、籌碼級距多週軌跡、同行／跨股背景、可能的反例、開始／結束日期判定依據、觀測缺口與替代假說。研究**成功、未成功、試探撤退、重新承接與部分收割**，不可只挑成功案例。

沒有足夠的縱向證據時，使用「**歷史階段未判定／待完整路徑稽核**」，不是「正常」「沒有播種」或「模型已證實失敗」。若已具多源歷史觀測且有合理反證測試，可提出帶不確定性的研究推論，**不要求不可能達到的100%確定性**。

## 5. 研究輸出驗收（FAIL-CLOSED）

凡聲稱「多年歷史播種／施肥／收割／撤回／重新承接／跨股輪動已判定」的報告，必須能提供：

- 逐股、逐日或可追溯至逐日的多年**原始 gross 買賣量與價格路徑**及來源SHA／母體版本；
- 在該判斷時點實際可得的所有相關集保歷史週序列及首次可觀測時間；
- 非固定窗口的歷史事件與自然轉折依據；若有局部窗口，明示那只是切片；
- 同期間完整的支持證據與反證，包括失敗／撤退／再試情形；
- 若有跨股輪動主張，提供各股可對齊的時間線及具體共同／反向動態；
- 原始資料覆蓋、缺漏、PIT與未經證實之意圖、成本及獲利限制；
- 清楚標記是「研究假說／暫定推論／完整審核後研究結論」，不得冒稱可下單訊號。

未具備這些時，長期階段輸出設為 \`HISTORICAL_CYCLE_UNVERIFIED\`；短期警報仍可保留，不得消失或被硬說成長期結論。

**即使總買賣摘要覆蓋2018–2026，只有「總和」而非可重查的事件路徑，也不能視為已通過長期階段檢核。**

## 6. 本次失誤的正式修正／舊報告治理

2026-11-09對八檔股票（2330、2454、2317、2408、6239、6446、3653、2412）曾過度依據2026-10-30至11-06的單週TDCC變化，分配「播種／持續累積／撤退／收割」等歷史階段。**這些階段標籤一律標記 \`PROVISIONAL_INVALID_AS_HISTORICAL_PHASE_CLAIM\`，不得引用成已確認衡策長期資金判定**。

這並非否認該週真實觀測，也非刪除已取得的原始多年交易資料；只是撤回不符合本規則的**解釋性結論**。未來須用完整時序重評，並保留正反證與原始證據，不得將一週改為五週／十二週就宣稱完成矯正。
