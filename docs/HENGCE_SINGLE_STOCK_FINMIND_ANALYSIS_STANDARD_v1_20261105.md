# HENGCE 衡策｜個股 FinMind 長期分析標準 v1.0

**生效日：2026-11-05。適用觸發：「衡策分析XXXX」、「分析某股」、「衡策分析某股」，含上市／上櫃；不改變「衡策掃一次」無啟用策略的狀態。**

## 核心承諾

不再只用當天股價或短期技術指標判斷股票。接到個股分析指令時，應依本規格完成 **FinMind 長期價量＋營收＋獲利＋資產負債＋現金流＋籌碼＋估值＋風險** 的交叉分析，並比對 **衡策既有 Canonical 母體**，提供可稽核、可重現、帶資料缺漏標示的結論。

這是**分析工作規格**，不是已驗證可獲利的選股模型；不產生自動買賣、券商委託、策略復活或資本授權。

## 1. 資料取得優先順序（強制）

1. 先讀 `governance/HENGCE_DATA_VESSEL_PRIORITY_LOCK_v1_20261103.json`，沿用既有 HENGCE 母體、GitHub EOD、live、歷史與 FinMind 正式監控血管。確認股票代號、公司名稱、TWSE/TPEx/其他市場與可用日期。
2. **既有原血管有資料**：必須取其當期值與原始收據的日期、筆數、SHA-256；並用該數值與長期 FinMind 個股資料交叉驗證；相同證據不能重複計算。
3. 使用者已明確要求為**個股研究**向 FinMind 取得長期相關資料；這項 2026-11-05 使用者指示授權**查詢個股分析所需資料**。若既有 FinMind HENGCE 接入可查該股票，優先走既有接入；否則可**按次、唯讀**查詢 FinMind 正式 API 作補充研究，標為 `EXTERNAL_FINMIND_RESEARCH`。不得將其默認升格為 Canonical，也不得用來偷偷填補 EOD 缺口。這是有邊界的個股研究授權，不是建立第二條收集血管、第二個母體或每日全市場抓取排程的授權。
4. **上市 TWSE**：對照 `/HENGCE_CANONICAL/HENGCE_2026_HIST_MOTHER.csv` 與 `/HENGCE_CANONICAL/HENGCE_CANONICAL_STATE.json`、`eod/YYYYMMDD/status.json`、`receipts/mother.json`；僅在代碼、日期和每腿收據有效時作為 Canonical 依據。
5. **上櫃 TPEx**：既有正式三腿母體主要是 TWSE，若 5289 這類上櫃股不在母體，**必須標示 NO_CANONICAL_COVERAGE**。不得說其資料已入 TWSE 母體，也不得將 FinMind TPEx 結果直接寫成母體資料。仍可給具出處的 FinMind 個股研究報告。
6. 資料若 `PENDING/NOT_READY/BLOCKED/MISSING`，明示缺漏，停止以不存在的正式母體數據下結論；不猜、不補假值、不冒充來源。外部補充資料不得改變該腿的正式權威狀態。
7. 所有分析註明 **as-of 時點、來源、交易所、最新完整收盤日、可用財報季度、資料區間與資料筆數**。當日盤中報價與歷史收盤日分開，不混入已完成日線的技術計算。

## 2. FinMind 個股研究資料矩陣（盡可能完整，資料集實際可用性以 API 回應為準）

| 維度 | FinMind 典型 dataset | 使用與檢查 |
|---|---|---|
| 長期日價量 | `TaiwanStockPrice` | 至少近 10 年，上市較短則自有資料起；OHLC、成交股數、交易金額；交易日去重、異常零值處理、原始 vs 還原口徑 |
| 還原價格 | `TaiwanStockPriceAdj`（僅在確有資料／權限時）| 優先用還原價評估長期投資報酬；失敗時僅稱**原始股價變動**，不可稱含息總報酬 |
| 櫃買／上市基準 | `TaiwanStockTotalReturnIndex`（TPEx、適用的市場代碼） | 對齊交易日；注意指數是含息而未還原個股價格不是，差值不等於嚴格 alpha |
| 月營收 | `TaiwanStockMonthRevenue` | 10 年以上可得期間；注意 `date` 可能是資料月份映射，依 `revenue_year/revenue_month` 判定歸屬月份、`create_time` 判定公開時點 |
| 法人買賣超 | `TaiwanStockInstitutionalInvestorsBuySell` | 外資／投信／自營；5/20/60 日與 6–12 個月趨勢；股票數量換算股／張需註明 |
| 融資融券 | `TaiwanStockMarginPurchaseShortSale` | 日餘額與變動、融資清洗、放空壓力；不將融資餘額絕對值等於所有散戶 |
| 季損益 | `TaiwanStockFinancialStatements` | EPS、營收、毛利、營益、淨利、毛利率、營益率及營業外；辨別單季 vs 累計 |
| 資產負債 | `TaiwanStockBalanceSheet` | 現金、應收、存貨、借款、負債、權益，連續季與年比較；注意相同科目定義 |
| 現金流 | `TaiwanStockCashFlowsStatement` | 營業現金流、稅後淨利、應收與存貨變化、投資支出、現金結餘；現金流季累計不可與單季淨利混算 |
| 估值 | `TaiwanStockPER` | PER、PBR、殖利率，估值高低與盈利週期；EPS 分母核對 |
| 股利／除權息 | `TaiwanStockDividend` | 除權日與股票股利、現金股利，釐清多年未還原價格的不可比性 |
| 其餘可用資料 | 集保股權、重大訊息、融券、財報附表及 FinMind 據證可用的相關 dataset | 適合的就取；明示沒權限、缺資料、延遲或不適用，不以「所有」為名杜撰 API 數字 |

**查詢範圍：**每次研究至少涵蓋 10 年日價量（可取則自上市／上櫃初日）；多年營收、季財報及現金流；3–12 個月法人與信用交易。量化結果均須說明取樣區間與去重、缺漏處理。不要只抓近五天後冒充「長期」。

## 3. 固定分析計算

**價格與趨勢**：年度收盤價（末日）、年度價格變化、近 5/20/60/120/240/480 日漲跌、5/20/60/120/240 日均線、距 52 週高低、長期高低點、最大回撤（收盤對收盤，另列盤中最高值）、年化波動（交易日數 252）、成交量對 20/60 日均量、關鍵價位。原始價 vs 還原價不得混算。

**財務與成長**：月營收 MoM/YoY、近 12 月 TTM（要有完整月份）、歷年營收、季 EPS、過去四季 EPS（TTM）、毛利與營益率、淨利、獲利是否來自本業；財報季度公告日晚於觀察日者不能當時可知。

**現金流品質**：同期間 `CFO/NetIncome`、近年營運現金流；應收帳款與存貨變動、短借及現金，清楚區分「高速成長導致營運資金占用」和「可能的獲利品質警訊」，不可未經證明指控造假。

**法人籌碼**：日別與 5/20/60 日累計買賣超，配合成交量比例、融資餘額變化；避免用單日回補推論中期翻多。

**估值敏感度**：說明 PER、PBR、殖利率，列至少 3 組不同未來 EPS 情境下的對應 PER；區分**假設**與財測，不臆造合理目標價。

**相對市場**：選擇正確上市／上櫃指數；用相同起迄日計算市場相對表現；未還原價對含息報酬指數僅供描述，禁止聲稱精確超額報酬或已驗證 alpha。

## 4. 報告順序（預設）

1. 股票識別、交易所、最新盤中／完整收盤日、數據覆蓋與血管／母體狀態（表）。
2. 10 年以上長期股價、年度表現、波動與回撤；20/60/120/240 日趨勢與均線。
3. 長期及近月營收、YoY/MoM、營收加速或放緩。
4. 季財報：EPS、毛利、營益率、本業 vs 業外，異常獲利是否具可持續性。
5. 現金流與資產負債表：CFO、應收、存貨、短借、現金與週轉風險。
6. 近 5/20/60 日法人、融資融券；與市場趨勢一致性。
7. 估值情境（非財測）、市場基準及強多／強空兩邊的依據。
8. 三種條件式未來情境、失效條件、接下來需確認的公告或數據。
9. 以「證據支持／不支持／資料不足」分別下結論；清楚揭露無已驗證交易模型權威；附來源、時間與原血管收據。

不提供沒有數據支持的預測漲幅、勝率、停利價或「模型買點」。若資料範圍、可取得來源有缺漏，標示哪些節可完成，不硬湊全套。

## 5. 禁止事項與權限邊界

- **Q017 已退役**：禁止回復、暗中使用 Q017/V43 等舊模型做排名或交易建議；「分析某股」≠「衡策掃一次」。
- **Canonical 不得虛構**：絕不因 FinMind 有數據就聲稱已進母體；任何入母體需要獨立、既有審計與橋接程序及收據。不得建立第二個母體或平行自動化收集排程。
- **不得偷看未來**：回測／歷史敘述以資訊當時已公開時點為準；公開日不明需標示。
- **價格還原口徑**：不可用未還原長期股價聲稱含息投資報酬；不可把上櫃股填進 TWSE-only Universe。
- **檢查失敗 fail-closed**：未驗證值不當成事實，不能給出「可靠進場」假訊號。
- **長期模型狀態**：本標準是研究流程，不構成獲利驗證；所有正式選股與交易權限維持零。若使用者之後明確改變分析偏好，再修訂新版本契約，保留審計紀錄。
